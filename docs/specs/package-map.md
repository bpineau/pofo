# Package implementation map

Use `go doc ./pkg/<name>` for the public API. This map locates implementation details for maintainers. The short task router is in `AGENTS.md`.

## Map

| Path | What lives there |

## Consumer analysis extensions

`marketdata/adjust.go` owns strict CPI and cash-index alignment, deflation, arithmetic excess returns and explicit day-count cash accrual. `Series.Cadence`, `Warnings` and `FXExtrapolatedBefore` survive CSV interchange and panel reconstruction. `analyze/source.go` adapts in-memory series and uses a client's Load contract; `adjust.go` produces Real and Excess studies. `metrics/options.go` selects cadence/risk-free assumptions; `json.go` emits undefined statistics as null. `optimize/research.go` owns frontier candidates and separate train/test evaluation. Robust regression, covariance regularization, block bootstrap uncertainty and single-period Brinson attribution live in `metrics`.
