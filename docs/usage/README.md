# Using pofo

Guides for people, written in the next documentation pass. Until they land,
the top-level [README](../../README.md) covers the command line and the
library, `go doc github.com/bpineau/pofo` is the library's entry point, and
[`examples/code`](../../examples/code/README.md) answers common questions
with runnable scripts.

Guides to come:

- **Getting started**: install, a first report, what the numbers mean.
- **The command line**: every mode of `pofo`, with examples.
- **The portfolio file format**: holdings, weights, `#meta` directives, the
  SIM convention.
- **The web app**: `pofo -serve`, the visualizer, share URLs, the FIRE
  simulator, the book.
- **The library**: which package answers which question, from loading a
  series to a full portfolio study.
- **FIRE and decumulation**: withdrawal plans, ruin probabilities, spending
  rules, and how to read the results.
- **Data and backcasts**: where every series comes from, what is bundled,
  what a reconstruction is and how far to trust it.
