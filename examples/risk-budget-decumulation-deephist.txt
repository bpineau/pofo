# Risk-budget decumulation, deep history -- forty years, on index stand-ins, read as a floor case.
#
# STATUS: research file, the deepest of the three, and the least faithful.
#   It carries the risk-budget-decumulation design back to 1986-12 by giving
#   up three of its lines for index-level stand-ins. The point is not to
#   flatter the design: the substitutions are measured below and they run
#   COOLER on return and HOTTER on risk than the real book, so what comes out
#   is a floor case, not a sales pitch.
#
# ## The ladder
#
#   risk-budget-decumulation.txt            2005-11, every line real
#   risk-budget-decumulation-longhist.txt   1996-03, floor de-indexed
#   this file                               1986-12, plus trend and small
#                                                    value at index level
#
# ## The three substitutions, and what each costs
#
#   TREND. The two fund reconstructions (DBMFE, RAEF) stop at 1996-03, the
#     first NAV of the deepest real donor, which is what walls the family off
#     from the 1987 crash and 1990. They become 20 points of BTOP50E: the
#     Barclay BTOP50 net managed-futures index, hedged to EUR, held at its own
#     ~8 % volatility rather than rescaled to the ~15 % a UCITS trend fund
#     targets. So the sleeve carries about half the risk the real one does,
#     and nothing here pretends otherwise: rescaling an index to a fund's
#     target is exactly what discredited an older reconstruction of this
#     period (docs/trend-reconstruction-design.md).
#   FLOOR. Euro linkers 1-10y (CHSN, 2005-11) become euro overnight cash
#     (XEON, rebuilt on the German money market before the euro existed).
#     Same argument as the longhist file, where the swap is measured.
#   SMALL VALUE. The global and European boutique funds (AVWS, Independance)
#     become 14 points of a US small-cap-value index (IE00BSPLC413, 1963).
#     This is the substitution that hurts: those funds are unusually calm and
#     a US SCV index is not.
#
#   Three reconstruction caveats specific to the deep era, on top of the
#   substitutions:
#   - CURRENCY WEIGHT: the small-value stand-in is 100 % USD where the
#     funds it replaces are mostly EUR (the boutiques) plus one USD line,
#     so this file carries roughly 9 extra points of dollar. Part of the
#     1990 drawdown below is that extra dollar, which the real book would
#     not have carried.
#   - PRE-EURO DURATION: the euro 25+ line before 1999 is rebuilt from an
#     EA19 aggregate yield whose ~11 % pre-convergence coupons (Italy near
#     13 %) no longer exist. Its +5.9 % through 1990 owes most of itself
#     to that carry: the same shock priced off a Bund-only curve was flat
#     (-0.4 %), and priced off 2020s coupons it is 2022. Do not read the
#     deep era as "euro duration shrugs off rate shocks".
#   - EARLY-INDEX CONCENTRATION: the BTOP50 of the late 1980s rests on the
#     handful of large programmes the sector then had, so its
#     spectacular first years (+57.6 % in 1987) are a concentrated record,
#     not a diversified-industry one.
#
#   Measured over 1996-03 to 2026-08, where the real book exists, all three
#   substitutions together:
#
#     metric              real lines (longhist)   this file's stand-ins
#     CAGR                       8.48 %                  7.54 %
#     volatility                 8.06 %                  8.87 %
#     Sharpe                       1.01                    0.83
#     max drawdown             -18.88 %                -19.49 %
#     worst rolling 5y           0.80 %                 -0.27 %
#
#   Both errors point the same way, which is the only reason this file is
#   worth reading: it gives up ~0.9 points of annual return and carries ~0.8
#   points more volatility than the book it stands for. Whatever it shows
#   surviving, the real allocation would have survived at least as well.
#   Isolated, the trend stand-in costs 0.74 points of CAGR and changes the
#   drawdown by 0.06; the small-value stand-in costs 0.18 points of CAGR and
#   adds 1.19 points of volatility; the floor stand-in is worth ~0.02.
#
# ## What forty years say (1986-12 to 2026-05, vs MSCI World in EUR)
#
#     metric              this book        MSCI World (EUR)
#     CAGR                  8.08 %              8.56 %
#     volatility            8.68 %             17.31 %
#     Sharpe                  0.90               0.56
#     max drawdown        -20.63 %            -60.27 %
#     max drawdown real   -23.73 %            -66.11 %
#     longest recovery     2.4 y               13.7 y
#     ... in real terms    3.3 y               14.4 y
#     worst rolling 5y     +0.04 %             -9.32 %
#     median rolling 5y    +7.41 %             +9.83 %
#
#   Half a point of compounding given up over four decades, against a
#   drawdown cut by two thirds and a recovery of 2.4 years instead of 13.7.
#   For a household spending from the portfolio, the third and fourth rows
#   are the ones that decide whether the plan survives; the first is the
#   price of admission.
#
# ## The finding worth carrying away
#
#   The worst drawdown of the whole forty years is NOT 2008, and not the
#   dotcom bust. It is 1989-06 to 1991-06 (-20.7 %): an oil spike, a
#   recession and rising rates at once, which is precisely the regime the
#   parent file names as its worst covered (gold and trend the only two legs,
#   long duration losing outright). The book's own design document predicted
#   where its weakness would be, and forty years of data put the weakness
#   exactly there.
#
#   The decomposition (calendar 1990, every line in EUR) says WHY, and the
#   why is not only oil:
#
#     world equity      -27.4 %     (-17.0 % in USD)
#     US small value    -34.4 %
#     gold              -13.0 %     ( -3.1 % in USD)
#     US 20+ unhedged    -6.7 %
#     euro 25+           +5.9 %
#     euro cash          +8.3 %
#     trend, hedged     +16.0 %
#
#   Two shocks stacked: the real one (oil, recession, rising rates) and a
#   CURRENCY one, the dollar falling hard against the mark. For a euro
#   holder that second shock turned both dollar hedges against the book at
#   once: gold lost 13 in EUR while barely moving in USD, and the "crisis
#   dollar" line lost money in the middle of a crisis. The legs that paid
#   were the hedged trend sleeve, the liability-currency duration and the
#   cash floor: every euro-denominated or euro-hedged line, and nothing
#   else. 1990 is thus a second measured failure of the crisis-dollar
#   playbook (2025 being the watched-live one) and the strongest single
#   piece of evidence for keeping the trend sleeve hedged, the floor in
#   euros and the US leg capped at 5.
#   Read it with the substitution in mind, in the direction that matters:
#   trend was strongly positive through that episode (the index returned
#   +15.3 % in 1990, and +57.6 % in 1987), so a sleeve at the real funds'
#   volatility would have cushioned more than this file shows. The -20.7 % is
#   pessimistic, not alarmist.
#
#   The second finding is 1994, the bond rout: US 20+ -17.0 %, euro 25+
#   -10.4 % and gold -11.2 % in EUR, all three hedges down together, trend
#   flat (+1.7 %) and cash at +7.1 % the only shelters. The book prints
#   -4.6 % for the year: survivable, but it is the regime where the
#   DIVERSIFICATION of the hedges is at its thinnest, and unlike 1990 it
#   offers no compensating leg. What decided the damage in both episodes
#   is the STARTING yield: 1990's euro long line carried 8-11 % coupons
#   into the shock and finished positive; 1994's carried less and lost 10;
#   2022's carried ~1 % and lost 38. The gauge of the next 1994 is today's
#   long yield, not yesterday's drawdown.
#
# ## What still cannot be tested, and why the 1970s are not here
#
#   No investable managed-futures record exists before 1986-12 (the index's
#   own start), no euro inflation-linked bond before 1998, no small-value
#   fund of this kind before the 1990s. A 1970s version of this book would
#   have to drop the trend sleeve, which carries a fifth of the capital and
#   most of the inflation defense, and would therefore be a different
#   portfolio wearing this one's name. The honest tools for that regime are
#   class-level, not ticker-level: `pofo -fire` resamples real historical
#   cohorts back to 1900 (bundled JST broad sample), which is the right
#   instrument for asking what a long stagflation does to a withdrawal plan.
#
