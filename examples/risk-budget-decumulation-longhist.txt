#   bounded by its euro linker line, so it has never met the dotcom bust.
#   This file gives that line up and reaches 1996-03 instead.

# ## What was substituted, and the licence for it
#
#   ONE change of substance: the 13 points of euro inflation-linked 1-10y
#   (CHSN, quotes from 2005-11) become 13 points of euro overnight cash
#   (XEON, rebuilt from the euro overnight rate and the German money market
#   before the euro existed, so it is never the binding constraint). Both are
#   short, low-volatility euro assets that pay the floor; what is lost is the
#   indexation, i.e. exactly the thing the parent file holds them for.
#   Plus one tidying: the two boutique small-value funds are folded into the
#   European one, which reaches 1990.
#
#   The substitution is licensed by measurement, not by assertion. Over
#   2005-11 to 2026-08, where the real linker line exists, the two books are
#   the same book:
#
#     metric              with linkers (CHSN)   this file (XEON)
#     CAGR                       7.98 %                7.96 %
#     volatility                 8.27 %                8.23 %
#     max drawdown             -19.14 %              -18.27 %
#     worst rolling 5y           0.67 %                0.92 %
#
#   Read that table twice, because it cuts both ways. It says the WHOLE-BOOK
#   statistics do not depend on the linker line, so carrying the book back on
#   a cash stand-in is honest. It does NOT say the two lines are
#   interchangeable: the parent file holds linkers for a regime (a long,
#   choppy inflation) that this window, 2022 included, never really delivered.
#   A file that swaps them can be trusted on sequence risk and equity bears,
#   and never on inflation protection.
#
# ## What the extra decade buys
#
#   1996-03 to 2026-08 covers the Asian crisis, LTCM, the dotcom top AND its
#   bust, 2008, 2011, 2020 and 2022. Measured over the whole window, pre-tax
#   and before any withdrawal: CAGR ~8.6 %, volatility ~8.1 %, worst drawdown
#   ~-18.5 %, worst rolling 5y ~+0.9 %/yr.

# ## The price is paid in advance (1997-1999)
#
#   Read the first three rows of that table before the rest: the book
#   compounds +58 % over 1997-1999 while the index compounds +115 %.
#   Three consecutive years of trailing a world tracker by 12 to 24
#   points, at the exact moment every conversation says diversification
#   is obsolete, are the entry fee for the three years that follow. That
#   is the behavioral shape of every regime-balanced book: it does not
#   merely "lag a little in bull markets", it looks broken at the top of
#   a mania, then pays it all back through the collapse. Whoever holds it
#   needs that sentence written down BEFORE 1999 arrives, not after; it
#   is the same asymmetry the parent file's trend protocol (section 4)
#   handles, at the scale of the whole book.
#
# ## What to distrust in it
#
#   THE TREND SLEEVE IS RECONSTRUCTED, not observed, before 2007: the donor
#     chain runs back through Man AHL Diversified, whose first NAV in 1996-03
#     is what sets this file's start. In 1996-1999 both trend lines sit on
#     that same donor and correlate at 0.84, so the "two managers against
#     manager risk" argument of the parent file is fictitious there. From
#     2000-01 the chains separate and the correlation falls to 0.33, which is
#     where the live era sits too, so the dotcom passage itself is honest.
#   THE DURATION LINES CROSS A ONE-WAY BOND MARKET: 1996-2020 is a falling
#     yield regime and the two long-duration lines are its beneficiaries.
#     Nothing in this window punishes them the way 2022 did.
#   GOLD STARTS ITS BULL in 2001, near the beginning of the window.
#   Read the file as evidence about SEQUENCE RISK and equity bears, which is
#   what it was built to test, and not as a general verdict.
